This is a starter post so you can see how the blog format works. Delete this
file (or edit it in place) and write your first real post.

**How to add a new post:**

1. Create a new file in `_posts/` named `YYYY-MM-DD-a-short-title.md`.
2. Add frontmatter at the top like this file has: a `title`, `date`, and one or
   more `tags` (try `nigeria-development`, `soccer`, or `data-science` to start,
   and add more as patterns emerge).
3. Write the post body in Markdown below the frontmatter.
4. Commit and push — GitHub Pages rebuilds automatically.

That's the whole workflow. No CMS, no extra tooling.
